# ChatMate AI

ChatMate AI 是一款 Android AI 聊天辅助工具。它可以读取当前聊天页面，必要时通过截图识别补充上下文，并根据系统提示词与当前会话配置生成个性化回复建议。

## 主要功能

- 聊天读取：针对微信、小红书、抖音私信过滤工具栏、关注状态和导航；QQ、Telegram、WhatsApp、短信及其他 App 使用通用适配
- 混合识别：先检查屏幕读取质量，再按需使用截图；输入框和键盘区域不作为已发送消息
- 自然回复：按聊天关系和最新情绪接话，提供自然、轻松、关心、邀约、拒绝五种快捷语气；换一句会参考上一版避免只换同义词
- 独立识别模式：可只使用屏幕读取或只使用截图
- 连续会话：同一 App 中的同一聊天会自动归入同一会话
- 多行消息：聊天气泡内的换行内容会作为同一条消息处理
- 个性化配置：会话可继承全局系统提示词，也可单独覆盖
- 微信式历史：左右气泡、头像、读取时间分隔，支持搜索和按 App 筛选；长按修正、复制、删除消息
- 联系人隔离：不同 App 和不同名称的联系人分别保存；修改备注保留识别关联，合并时从联系人列表选择
- 快捷面板开关：可从 Android 系统快捷面板启动或关闭聊天助手

## 使用方法

1. 在首页配置 API、模型和全局系统提示词。
2. 选择识别方式；推荐使用“混合”。
3. 按首页提示开启悬浮窗、无障碍或截图权限。
4. 开启首页底部的“聊天助手”开关。
5. 打开具体聊天，露出联系人名称和最近消息，点击悬浮按钮。模型已配置且最新消息来自对方、身份无待确认项时会自动起草。
6. 需要时点按气泡修正内容或身份，或选择快捷语气、填写补充想法。
7. 修改推荐回复后点“复制并返回聊天”，回到原 App 粘贴发送。需要新建议时点“换一句”。

信息流、评论区和聊天列表不作为私信读取。识别仅包含当前可见消息与本地已读取历史，不会自动翻页。截图、群聊、昵称相同的联系人及不同 App 版本仍可能需要人工校正；看不到的图片、视频和语音内容不会由模型凭空补全。

识别与回复策略、测试方式和已知限制见 [交互重构说明](docs/chat-experience.md)。

在三星 One UI 中，展开快捷面板并进入“编辑按钮”，从“可用按钮”中将“聊天助手”拖到快捷面板。应用不会主动弹出添加窗口。

## 构建

需要 JDK 17 和 Android SDK。复制 `local.properties.template` 为 `local.properties`，并设置 `sdk.dir`。

```bash
./gradlew assembleDebug
```

调试 APK 输出到 `app/build/outputs/apk/debug/`。

也可以直接运行构建脚本，并在菜单中选择 Debug、Release 或两者：

```bash
./build-apk.sh
```

命令行模式：`./build-apk.sh debug`、`./build-apk.sh release` 或 `./build-apk.sh all`。首次构建 Release 时，脚本会在 `~/.android/chatmate-ai-release.jks` 创建正式发布密钥；请妥善备份密钥及密码。

## 隐私

应用配置保存在本地，API Key 使用加密存储。识别到的聊天内容仅会发送给你自行配置的 AI 服务。点击悬浮助手后可能自动生成，停止或离开回复页会取消当前请求；推荐文本只复制，不自动发送。屏幕读取按用户操作触发，不在无障碍事件回调中采集聊天；排除密码节点、输入框草稿和键盘窗口。本次改动没有新增系统权限。请在获得聊天参与者许可并遵守相关法律与平台规则的前提下使用。
